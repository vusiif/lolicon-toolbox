# 火星文还原与 AI 手动测试

入口仍为“文本与编码 → 文本风格转换”。顶部提供转换模式和还原模式。本地操作不调用网络；AI 复用设置中的 OpenAI 兼容 API 地址、模型和密钥。

## 本地还原

1. 切换还原模式，种子与强度应隐藏。输入 `☆莪愛沵☆`，点“本地还原”；成对装饰可移除，候选中应有 `我爱你`。存在歧义时默认结果可能保留某个火星字，需比较其他候选。
2. 输入 `妑` 再还原。“保留歧义”应保留该字，其他候选给出不同原字。悬停状态栏可查看最多 32 处映射歧义。候选不按语义概率排序，也不覆盖所有组合。
3. 在文本两端加 Tab、NBSP、空行，混入 `👍🏽`、`é`。未知完整 EGC、首尾空白及行数应保留。取消“移除识别到的成对行装饰”后装饰应保留；未匹配的装饰不移除。
4. 默认结果只反查唯一映射；最多三个替换策略为歧义给出不同候选，并保留规范化原文作对照。相同候选去重，按钮可能少于五个。点不同候选后输出与复制内容应对应。
5. 宽屏文本和按钮对齐；窄窗口上下排列，候选分两列，通过滚动访问输出和 AI 控件。

映射唯一不能证明是原文：原输入已含火星字或繁体字时，还原可能改变它。包装符号去除也是启发式，可取消勾选。不承诺无损往返。

## AI 转换与还原

1. 在设置中填写并保存接口地址、模型与密钥。提示应显示发送目标与模型；没有配置时 AI 按钮不可用。不要发送密钥给本喵。
2. 转换模式输入短句，可先本地转换，再点“AI 转换”。仅点击该按钮发起请求，包含输入、已有本地结果、强度、种子和最多 32 条匹配规则提示；AI 也可直接处理输入。
3. 还原模式先对两行 `☆莪愛沵☆`、`妑` 本地还原，再点“AI 还原”。请求包含原输入、本地候选和最多 32 处歧义。AI 输出单独显示为“AI 参考结果”，解释说明推断，不可当作已验证原文。
4. 用“本地结果／AI 参考结果”切换，确认本地候选仍保留。复制当前结果到记事本，检查完整正文与换行，文本不会作为 HTML 执行。
5. 请求中显示用时、接收字符数和思考／回复状态；最长 90 秒。“取消 AI”应停止请求并保留本地结果。修改输入、种子、模式或接口设置会取消旧请求、清除旧结果；迟到响应不能覆盖新输入。
6. 400、401、429、超时、断流或错误 JSON 应显示可读错误，保留本地结果。AI 输入上限为规范化 UTF-8 16 KiB，超限按钮不可用；过大的候选上下文会被请求大小检查拒绝。

AI 同种子不保证同结果；本地转换保持原种子契约。真实服务效果需要用自己的接口手测。本次自动验证仅使用 localhost 假服务，未调用付费模型或发送真实文本；覆盖任务提示、负载、结果切换、取消、输入失效和 HTTP 400 保留本地结果。共享 provider 的 SSE、授权、超时和严格响应格式也有回归覆盖。

系统剪贴板曾被 SogouCloud 占用，自动 UI 测试使用注入写入器检查完整负载及失败提示，真实复制粘贴仍请按第 4 步验收。
