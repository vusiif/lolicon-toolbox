# 音色设计：最小页面手工验收

当前是 Stage 2 最小接入版本：可以提交声音描述和试听文案，收到并校验 WAV。
此版本暂不提供播放、保存音频、描述构建器或 A/B。音频仅存在当前进程内，关闭软件后不会保留。
自动测试只调用本机模拟接口，没有用真实密钥、额度或收费 API。

## 真实 MiMo 接入

1. 打开工具箱「设置」。API 地址填写 `https://api.xiaomimimo.com/v1`，密钥填写有 VoiceDesign 权限的 MiMo API key，保存。
2. 设置中的模型字段仍供文本 AI 工具使用，可以保留当前值。音色设计固定调用 `mimo-v2.5-tts-voicedesign`，不读取这个模型字段。
3. 打开「音频与语音 → 音色设计」。确认页面显示主机 `api.xiaomimimo.com` 和固定音色设计模型。
4. 声音描述填写「温暖、沉稳的成年男性声音，咬字清晰，语速舒缓。」；试听文本填写「你好，欢迎来到工具箱。今天我们一起设计一个新的声音。」。
5. 填写文本或切换页面不会发起请求。点击「生成试听」才会将这两段文本发送到配置的接口，可能产生费用。
6. 确认出现等待秒数，生成按钮禁用、取消按钮可用。成功后应显示「已收到并校验 WAV」和音频大小。

此步骤验证连通性及 WAV 格式；实际音色质量和播放需在下一阶段验收。
若成功耗时接近 90 秒，请记录耗时、模型名和报错文字，不要发送密钥或包含 Authorization 的日志。

## 取消与状态

- 请求期间点击取消，状态变为已取消；随后可再次生成。
- 请求期间修改任一文本，旧请求取消，旧结果不得覆盖新输入。
- 生成成功后修改文本，应提示上一轮音频已过期。
- 请求期间离开页面或保存新的 API 配置，旧请求应取消；回到页面不会自动重试。
- 清空后两个输入和音频均清除，生成按钮禁用。
- 超过描述 8 KiB / 文案 16 KiB UTF-8 时生成按钮禁用，按钮提示解释限制。

## 错误与界面

- 无效密钥应返回认证错误；不显示密钥或服务端原文。
- 不支持 VoiceDesign 的接口可能返回 HTTP 400/404；应显示状态码并允许调整配置后重试。
- 不完整或非 WAV 音频必须报错，不显示成功。90 秒超时后可以再次生成。
- 简中、繁中、英文文案切换正常；主题切换保留成功结果。
- 宽窗口两个输入并排，窄窗口上下排列，无按钮遮挡和整页横向滚动。
- Base64、乱码修复、火星文转换仍可正常使用。共享 API 配置变更也会影响其他 AI 工具，请使用对应接口支持的文本模型。

后续顺序：真实接口验证 → Qt Multimedia 播放/停止和保存 WAV → 描述辅助构建 → A/B → 设计参数 JSON。
