# 文本风格转换 V1

入口：**文本与编码 → 文本风格转换**（`text.style_converter`）。内置包为经典火星文 `mars_classic` 2.0.0，提供轻度、中度、重度。本地转换，无 AI、运行时外部规则导入、反向还原或历史记录。

## 使用与复现

风格与强度位于同一行，下方是始终可见的种子框。页面打开时选取随机数字种子；“转换”使用框内种子，“随机转换”一次完成更换种子和转换。种子右侧的骰子只更换种子，不执行转换，修改种子会清除旧输出。不同种子可能得到相同输出。页面不再提供复现详情或参数复制区域。

输入框即时限制为最多 64 个 ASCII 字母或数字，拒绝空格、符号、中文、全角数字和超范围纯数字。字母统一为小写 ASCII，`CAT42` 与 `cat42` 等价，保留文字形式以便以后加入彩蛋；目前未实现彩蛋。清空种子时固定种子转换不可用，可点击骰子补充，或直接随机转换。

纯数字仍直接映射到 0–18446744073709551615 的无符号 64 位值，成功后去除前导零（`decimal-u64-v1`），保持旧样例输出。含字母种子使用 `ascii-alnum-sha256be64-v1`：对 ASCII 字节 `toolbox-text-style-seed-v1:` 加规范化种子计算 SHA-256，将前 8 字节按大端映射为数值；例如 `cat42` 映射到 `0x983f1e82483d66e9`。不使用运行时随机化的字符串哈希或 ASCII 码直接拼接。64 位映射可能碰撞，不承诺不同文本种子与输出一一对应。

清空保留种子与强度。设置只保存强度，不保存原文、输出、种子或文本哈希。修改输入、风格、强度或种子立即使旧结果失效。后台任务可取消，迟到结果不能覆盖新输入；切换界面语言和主题不改变生成结果。

要复现文字结果，保留原文、风格、强度和种子，并使用相同规则包与 Qt 运行环境版本。内部结果仍记录种子映射和版本信息，用于验证算法；页面不展示或导出这些字段。

## 转换契约

- 仅把 CRLF、CR、U+2028、U+2029 统一为 LF，不做 NFC、大小写或简繁转换。
- 使用 Qt `QTextBoundaryFinder::Grapheme` 按原始整行切分 EGC；规则只能从完整 EGC 边界匹配。未知字符、组合字符、emoji 和空白原样保留。
- 在已启用规则中选最长精确匹配；概率门未通过仍消耗整个匹配源，不回退短规则。输出不再次匹配。
- 每行先替换，再为非空白正文添加成对装饰；原始首尾空白保留在装饰之外。纯空白行不消耗装饰随机数，不增加末尾换行。
- 固定 Unicode White_Space 标量集合，只有全部标量均为空白的 EGC 才算空白。
- RNG 为 `splitmix64-v1`，64 位无符号溢出；固定加数 9E3779B97F4A7C15，乘数 BF58476D1CE4E5B9、94D049BB133111EB，移位 30/27/31。有界采样拒绝小于 `(uint64_t(0)-bound)%bound` 的随机值；按候选声明顺序累加权重。0/10000 概率门及单候选选择不消耗随机数。

引擎版本 `1.0.0`，规范化版本 `line-endings-lf-v1`；引擎直接调用的数值元数据 schema 1，页面内部的文本种子结果元数据 schema 2。记录实际 Qt 版本与 EGC 实现信息。升级 Qt 可能改变 Unicode 边界，不能只凭相同种子保证跨版本一致。

## 规则与边界

2.0.0 将三份参考数据及原有规则合并为 4791 条字符规则、38 条词组规则，共 4829 条。保留 614 条多候选规则；重复引用不增加权重，原样替换不进入转换规则。Gist 的繁体源字也参与整理。新增 dictionary 分组在三档强度中启用，原有词组与装饰保留。数据更新可能改变旧种子的输出；引擎随机算法未改。

原始自整理包、标准化参考关系、反向候选索引和合并报告保存在 `resources/styles/curation/`。运行 `scripts/Merge-Martian-Dictionaries.py` 生成规则包，构建时 `--check` 验证生成结果未过期。反向索引只记录候选，没有实现还原页面，不宣称唯一或无损还原。来源和许可状态见 [规则来源](Style-Data-Sources.md)。

UTF-8 JSON 内置为 Qt 资源。顶层固定包含 `schema_version`、`metadata`、`rule_groups`、`presets`、`rules`、`decorators`。三个预设分别配置规则组、替换概率、装饰概率和装饰 ID；规则声明 ID、character/phrase、组、源和带正整数权重的候选；装饰声明前缀、后缀及权重。

加载器严格检查字段、类型、引用、重复规则 ID/源/候选、无效 Unicode 和禁止控制字符。权重 1–1000000；最多 16 组、10000 条规则、每规则 16 候选、64 个装饰；源最长 64 EGC/256 UTF-16 单元，候选最长 128 单元，装饰前后缀各 32 单元。JSON 最大 2 MiB，不允许 BOM。ZWJ/ZWNJ/变体选择符可用。

Qt JSON 对象解析不能保留重复键；构建阶段的 `scripts/Check-Style-Json.py` 使用标准库检查原始 JSON 重复键、非法 UTF-8/BOM/NaN 等，运行时再检查完整 schema。Python 3 仅为构建依赖，发布包运行不需要 Python。

原始输入最多 524288 UTF-16 单元，规范化输入最多 256 KiB UTF-8；输出最多 2 MiB UTF-8 / 2097152 UTF-16 单元。转换预算 5 秒，有分段、索引、匹配和随机采样取消检查。失败不返回部分输出、统计或参数。

详见 [手动测试](Text-Style-Testing.md) 与 [规则来源](Style-Data-Sources.md)。
