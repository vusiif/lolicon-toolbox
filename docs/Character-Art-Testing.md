# 字符画生成器：功能与验收

入口：图片工具 → 字符画生成器。全部本地处理，无上传、AI 或历史记录。

## 使用

1. 打开 PNG 或 JPEG，确认文件名、像素尺寸和右侧缩略图。
2. 设置列数（10–240），选择基础、密集或自定义字符集。默认 80 列。
3. 按需调整亮度（-1 到 1）、对比度（0 到 3）、反色，点击生成。
4. 预览使用内置 Maple 字体。缩放（25–200%）仅改变查看尺寸，不改变结果或导出尺寸；预览可横向、纵向滚动。
5. 复制文本，或保存 UTF-8 TXT；导出 PNG 可保留与软件预览相同的字形布局。
6. 所有文件导出只创建新文件；若路径已存在，会提示换一个路径，不覆盖原文件。

复制文本到其他软件后会采用那个软件的字体，字符画可能变形；需要保留视觉效果时请导出 PNG。

## Maple 资源与算法

- 使用用户提供的 `MapleMonoNL-NFMono-CN-Regular.ttf`，实际内部名称 Maple Mono NL NFMono CN Regular，版本 7.900。
- SHA256：`f01646c491179bc0cc547d9d5e6e6dc3e3894bd0c13ac2bffaf6ae4acb04b0a1`，CMake 固定校验。字体未经修改，许可和来源见第三方目录的 OFL.txt / FONT-NOTICE.md。
- 字体嵌入 Qt 资源，QRawFont 直接绘制该字体的 glyph，不走系统字体补字。失败时禁用生成。
- 首次懒加载页面时，在 20 pixel、无 hinting、黑字白底、文本抗锯齿下校准两个内置 ASCII 字符集。
- 字符格宽度来自 M 的 advance 向上取整，高度来自 ascent + descent + leading 向上取整。当前 Windows / Qt 环境测得 12×27，基线来自 ascent。
- 密度是整个字符格像素的平均黑度。按密度升序排序，相同密度按 token 文本排序；传统 ASCII ramp 仅作候选集合，其输入顺序不决定最终明暗顺序。
- Token 与结构化网格使用 QString，未把字符模型写死为 char；V1 用户不能导入自定义字符集。
- 行数为 `round(图片高度 / 图片宽度 × 列数 × cell宽度 / cell高度)`，最少一行。超过 300 行报错，请减少列数。
- 先在白底合成透明像素，再平滑缩放采样；亮度用固定 RGB 系数 0.2126 / 0.7152 / 0.0722，执行亮度 → 对比度 → 反色 → clamp → 线性量化到已校准 token 顺序。
- 校准产生的字形格缓存同时用于预览与 PNG，PNG 独立渲染结构化网格，不截取控件。导出四边各留 8 像素空白。
- TXT 为 UTF-8、LF 换行、无 BOM，保留行尾空格。
- 图片读取和生成使用现有 QtConcurrent / revision / cancel 模式；输入或参数变更清除旧结果，迟到结果不能覆盖新状态。

## 资源预算

这些是工具本地限制，不是图片格式本身的限制：

| 项目 | 上限 |
| --- | --- |
| 文件大小 | 32 MiB |
| 单边尺寸 | 8192 像素 |
| 输入像素 | 16×1024×1024 |
| 列数 / 行数 | 240 / 300 |
| PNG 渲染像素 | 32×1024×1024 |
| 生成时间 | 5 秒 |

Qt 图片解码仍可能有格式转换副本；高位深输入内存大于普通 RGB 图像。
取消解码不会强行终止 Qt 解码器，界面先使其结果失效，后台返回后释放结果。
预览缩放通过绘制变换实现，不分配整幅高倍缩放图片。

## 自动验证与性能

`TestCharacterArt` 验证资源加载、原生 glyph 支持、空格密度为零、密度范围/顺序/重复校准、比例公式、亮度和反色、LF 文本、取消、文件/尺寸/像素限制、PNG/JPEG 与 EXIF 方向、损坏/缺失图片、PNG 尺寸和稳定渲染、TXT 不覆盖。
`TestUi::characterArtWorkflow` 验证懒加载、生成、复制完整文本、TXT/PNG 导出、参数失效、取消、清空、语言/主题、缩放与窄窗口。
测试剪贴板使用注入的写入函数；真实系统剪贴板由手工检查，避免第三方剪贴板占用造成不稳定。

当前 Qt 6.11.2 / MSVC Release 环境，校准约 34 ms，2048×2048 图片生成并渲染 240 列约 27 ms。
这是核心耗时，不包括磁盘解码、文件对话框和 PNG 压缩，也不是所有硬件的速度保证。

## 手工检查

- 正方形、圆形、宽图、高图生成后比例合理；透明 PNG 白底区域为空格。
- 黑到白渐变明暗方向正常，反色后相反；基础和密集字符集均可生成。
- 调整列数/亮度/对比度/字符集/反色后旧结果立即失效，必须重新生成；缩放、主题、语言不改变结果。
- PNG 内容与预览相同，尺寸为列数×cell宽 +16、行数×cell高 +16。
- TXT 用支持等宽字体的软件打开，检查换行和行尾空格；复制到纯文本编辑器检查内容完整。
- 选择损坏文件、不存在路径、过大图片或已有导出路径应明确失败，原图和原输出文件不变。
- 页面切换、清空、取消后旧任务不应重新出现。
- Base64、乱码修复、火星文和音色设计继续正常使用。

## V2 自定义字符集

选择「自定义」，填写如「春夏秋冬山水风月」「我爱Toolbox」「♥★●○◆◇」的字符。
程序按 Unicode grapheme cluster 切分并去重，自动测量 Maple 字形密度并排序；不是按输入顺序排列明暗。
默认「加入空格」勾选，提供纯白的空白格；取消勾选后只使用你填写的字符。

限制为 2–128 个不同字素（包含可选空格），输入最多 2048 个 UTF-16 单元、单个字素最多 32 个单元。
不接受换行、制表符、不可打印或零宽字素。字形缺失、不能以 Maple 绘制或无法对齐等宽网格时列出具体字素，并禁用生成；不会偷偷丢弃这些字符或改用系统字体。
「AB」是 A、B 两个字素，不是一个多字符 token。

自定义校准使用内置字体的 QTextLayout shaping，检查所有实际 glyph run 仍来自同一 Maple 资源。
混用 ASCII 与汉字时按最宽字素取公共格宽（基础格宽的整数倍），重新计算行数；窄字素在 TXT 中补尾随空格，以保持 Maple 的等宽格对齐。预览和 PNG 共用这次校准的字形缓存。
组合字素不会按 UTF-16 拆散。组合附加符的具体支持取决于字体，未支持的序列会完整列出。

修改自定义字符或空格选项会使旧结果失效；用户输入只保存在本次页面会话，不写设置或长期历史。
自动测试覆盖中文、混排、组合字素、重复字符、非法 Unicode、数量限制、明确拒绝不支持字符、格宽与 TXT 补空格、生成/导出及切回内置字符集。

多字体、彩色、抖动、GIF/视频仍未加入。
