# 文本风格转换手动测试

启动本次发布包，进入“文本与编码 → 文本风格转换”。以下测试不需要 API。

## 固定样例

在“强度”下方的种子框中设置 `42`，粘贴下面两行（第二行末尾不额外换行）：

```text
你好，我喜欢你！ABC 123 😀
谢谢朋友，晚安。
```

分别选择轻度、中度、重度，再点转换。预期如下：

轻度：

```text
你恏，我喜欢伱！ABC 123 😀
谢谢朋友，晚安。
```

中度：

```text
伱恏，峩囍歡伱！ABC 123 😀
謝謝倗叐，晩咹。
```

重度：

```text
☆伱恏，峩囍歡伱！ABC 123 😀☆
☆謝謝倗叐，晩咹。☆
```

对应命中/替换/装饰行分别为 `4/2/0`、`6/6/0`、`6/6/2`。样例绑定规则包 SHA-256 `f72b1ddad482a6f53a4c5433c6f7db20146e9649d369f566536b25089ff6b202`，Qt 6.11.2。

## 操作检查

1. 重复转换应完全一致；点种子右侧骰子应改变种子并清空旧输出，但不执行转换；再点转换得到新结果，允许偶然得到相同输出。种子填 `00042` 成功后变为 `42`。最大值 `18446744073709551615` 可用；负数、小数、符号、中文、全角数字、超最大值纯数字应在输入/粘贴时直接拒绝。
2. 输入 `CAT42` 应显示 `cat42`，与手工输入 `cat42` 得到相同结果。复制种子保留 `cat42`；生成参数应记录 `seed_text=cat42`、`seed_mapping_id=ascii-alnum-sha256be64-v1`，数值种子对应十六进制 `983f1e82483d66e9`。清空种子应禁用转换；点击骰子恢复可用。
3. 成功后修改原文、强度或种子，应立即清除旧输出、统计和生成参数。清空后种子和强度应保留；关闭并重启只恢复强度及高级区域状态，正文为空，种子为新随机值。
4. 复制输出粘贴到记事本，检查完整正文；展开“复现详情”复制参数，应为合法 JSON，种子是字符串，包含完整包哈希和规范化输入哈希，不含原文/输出。修改输入后不能复制旧参数。
5. 在正文两端加空格、Tab、NBSP，添加空行、`é`、`👍🏽`、`👨‍👩‍👧‍👦`、`🇨🇳`；未知序列应完整保留。重度只装饰非空白正文，保留首尾空白和行数。`<b>你好</b>` 应按普通文本显示，不执行 HTML。
6. 分别切换简体、繁体、英文及深浅主题，检查标签、导航和可读性，已生成正文不变。风格和强度始终同一行。宽屏两块文本区域左右排列且底部按钮对齐；缩小到约 640×480 时上下排列，按钮各自跟随文本区域，通过滚动访问高级区域。
7. 使用接近 256 KiB 的混合文本转换；转换期间仍可编辑输入，迟到结果不应覆盖新输入。若任务仍在运行，可取消；超限输入应给出错误而非部分结果。

## 已完成的自动验证与待手测项

固定随机向量、拒绝采样、文档示例、正式包样例、Unicode EGC、严格 schema、边界、超限、取消、超时、并发与受控迟到任务已有回归测试。隐藏原生 Qt 窗口测试覆盖页面状态、语言/主题、布局及复制完整负载和失败反馈。

本机测试期间 SogouCloud 占用系统剪贴板。新页面的复制负载和失败反馈使用注入写入器验证，真实系统剪贴板复制仍需上述第 4 步亲自验收；失败时应提示重试并保留结果，不应显示“已复制”。
