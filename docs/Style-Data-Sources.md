# 风格规则包来源

## mars_classic 1.0.0

- 数据：`resources/styles/mars_classic.json`，UTF-8，无 BOM；作为 Qt 资源内置。
- 覆盖：98 条字符规则、38 条词组规则，共 136 条；20 条规则有多个候选；2 个成对行装饰。
- 分组：core（基础字形）、extended（扩展字形与词组）、expressive（趣味聊天表达）。轻度只启用 core，替换率 4500/10000；中度启用 core+extended，替换率 10000/10000；重度启用全部规则，替换率与装饰率均 10000/10000。
- 原始文件 SHA-256：`f72b1ddad482a6f53a4c5433c6f7db20146e9649d369f566536b25089ff6b202`。
- 来源：为本工具新整理的常见字形与聊天词组映射，未导入外部词典或网络数据集。字形/谐音/趣味替换可能改变阅读感受，不保证语义等价，用户应检查生成文本。
- 许可：仅此新增规则数据采用 MIT，完整声明见 `resources/styles/LICENSE.txt`；不改变项目其他文件或第三方组件的许可。

`tests/data/style-demo.json` 是用户提供开发计划中的演示规则，仅用于随机算法黄金回归，与正式覆盖量分开计算。`style-release-goldens.json` 固定正式包样例，预期由独立 Python 整数随机流计算生成；该参考只处理样例中的简单 CJK/ASCII，不能作为通用 Unicode 分段实现。

规则源与 ID 唯一，候选声明顺序、权重、概率及装饰声明順序参与复现契约。修改包字节即改变 SHA-256；修改转换行为时需要更新包版本及对应固定样例。不能仅靠调整展示排序承诺旧种子输出保持不变。
